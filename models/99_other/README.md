# 雄風發射箱：高面數外觀版 v2

四款模型分成四個資料夾與四個壓縮檔。這版完成高面數外觀細化；**實物精確尺寸仍未取得，不能稱為原廠等尺寸重建**。使用者表示沒有實測尺寸或帶尺寸資料，因此絕對尺度保留為估算。

## 交付

1. `rocn_hf-3_quad_launcher`：一箱標準型雄三。
2. `rocn_hf-2_hf-3_mixed_quad_launcher`：依使用者修正，改為成功級單組混裝架，二雄二＋二雄三，合計四箱。雄二與雄三兩列箱殼淨距由0.16 m加大為0.45 m；外側附件會占用部分淨距。此為使用者要求的視覺間距調整，非實艦量測值。
3. `rocn_hf-2_quad_launcher`：依使用者修正，改為康定級單組雄二四聯裝，合計四箱，不含艦體遮蔽艙壁。左右兩列箱殼淨距加大為0.45 m；此為視覺間距調整，非實艦量測值。
4. `rocn_hf-3_mobile_quad_launcher`：四箱雄三與展示模型照片啟發的舉升底架外觀，不含完整車輛。

每款有主 OBJ、同名 MTL、`_game.obj` 座標轉換版、實際網格多角度渲染 `preview.png`、`manifest.json`。主 OBJ 含明確頂點法線，圓角與圓柱可平滑顯示；物件依箱體／肋條／箱蓋／鉸鏈／附件／底架分開命名。材質不依賴外部貼圖。

主 OBJ 單位為公尺，Z 向上；單箱、成功級單組與康定級單組的指定前端均為 +X。成功級及康定級的底架在XY平面置中，可由使用者複製旋轉後安排到船上，不再把兩組一起輸出。轉換版映射為 `(y,z,x)/100`，即 Y 向上、原 +X 轉為 +Z。未在 Sea Power 內驗證，尚未配置武器掛點、動畫或載入設定。高面數主檔用於編輯與展示，直接用於遊戲前應製作 LOD。

## 相較 v1 的實際改動

- 重建具有多段圓角、端部倒圓及平滑法線的箱體與蓋板。
- 以實體側肋和頂肋取代 v1 穿過箱體的整片環帶造型；增加側面雙縱向條。
- 雄三採八個、雄二採六個横框作外觀近似；由公開近照推估，包含端部框，非已量測原廠數量表。
- 加入箱蓋密封縫、雄二內縮面板、雄三前端小方形標記及小蓋板。
- 雄三未有照片支持的端面保留簡化；成功級依使用者新提供照片修正目前觀看端面的蓋板與鉸鏈，詳見末節。
- 鉸鏈拆成葉片、圓柱節與軸，加入外觀螺栓／墊圈及側面固定塊。小零件的位置、尺寸與數量均為美術近似。
- 艦載四柱展示台改成開放式斜撐與分離底腳。
- 車載款改成滑架、樞軸與舉升套筒的外觀量體，參考中科院公開展覽模型；不能據此視為量產車的機構重建。

## 尺寸查證結果

2026-09-10 查閱中科院雄二、雄三官方產品頁及公開照片，未取得發射箱本體的官方長寬高或比例尺三視圖。搜尋結果中的彈體長度不等於箱長，增程型、雄二E與天弓的箱體尺寸也不能挪用到本模型。

| 參數 | v2 採用值 | 證據等級 |
|---|---|---|
| 雄三箱殼 L×W×H | 6.80×1.35×1.45 m | 保留 v1 的未驗證美術尺度 |
| 雄二箱殼 L×W×H | 5.25×0.84×0.90 m | 保留 v1 的未驗證美術尺度 |
| 艦載箱姿態 | 35° | 根據側照調整視覺姿態；不是精確安裝角 |
| 車載箱姿態 | 45° | 展示用姿態；非官方固定角度 |
| 箱架間距與底腳 | 依本次模型構圖 | 未取得甲板安裝圖 |
| 螺栓與鉸鏈尺寸 | 美術參數 | 未量測，不能作加工尺寸 |

以上為箱殼參數，端蓋、肋條與支座會增加最終外接尺寸；每檔實際外接尺寸列於 manifest。**高面數不代表尺寸更準確。** 有實測尺度後可修改 `SPECS` 重建，且应同步校正所有附件与掛架，不可只用某一根欄杆或照片中人物當作精密標尺。

## 檢查與重建

`build_highpoly.py` 使用 Python、NumPy、Pillow，內含深度緩衝預覽工具。執行可重建四款；可附加資料夾名稱只重建某款。

`validate_package.py` 讀回實際 OBJ，檢查面索引、非零面積、閉合邊、法線、物件名稱、材質、座標轉換、箱數與箱殼交疊。模型包含許多互相接觸的獨立零件，不是適合直接實體列印的單一布林合併網格。此版沒有UV、開蓋動畫或遊戲內測試。

## 成功級左右及後端對齊修正
依使用者提供圖片的後端觀看方向：左側為雄二兩箱，右側為雄三兩箱。此處左右以後端視角定義，從前端觀看會反轉。成功級單組保持45公分列間箱殼淨距；兩種箱體以沿傾斜箱軸的後端面對齊，雄二整列沿箱軸後移0.775公尺，箱體本身不縮放。此移動量由目前兩箱模型的長度差計算，不是新取得的實測尺寸。預覽補上後端視圖；檢查程式讀回實際OBJ驗證左右位置和後端平面。
