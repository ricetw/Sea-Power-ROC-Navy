# 05 砲彈、槍彈與彈種型號

[回總覽](README.md)｜整理日期：2026-09-10

**最重要的限制：公開資料通常能確認海軍用某口徑火砲，卻不公開各年度採購的完整彈體Mark／Mod、信管與裝藥組合。** 本表把能核實的產品型號列出，也明確區分其是否已證實由海軍使用。未找到型號就是「待核」，不以美軍彈種大全填成台灣清單。

HE為高爆；HEI為高爆燃燒；AP為穿甲；APDS為脫殼穿甲；SAP為半穿甲；TP為練習；BL&P為盲裝填練習；VT為近炸信管類別。這些多是**彈種／功能名稱，不是完整產品型號**。

## 一、艦砲彈藥

| 對應武器／口徑 | 時期 | 可列彈種或型號 | 台灣海軍使用證據 |
|---|---|---|---|
| 日製100mm砲彈 | 1950年代 | 高爆等彈種；正式型號待核 | 日製再武裝有艦史，但100mm具體配置與彈型待核。[H06][H06] |
| 日製120mm砲彈 | 1950年代 | 高爆等彈種；正式型號待核 | 不把所有日製艦砲寫成127mm；批次待核。[H06][H06] |
| 日製127mm砲彈 | 1950年代 | 日製砲專用彈；正式型號待核 | 不等同美式5吋砲彈；是否採用某日軍「零式／通常彈」未確證。[H06][H06] |
| 美式5吋／25彈藥 | 1950年代後 | HC／AA等為查核彈種；Mark待核 | 候選武器對應彈藥，尚未取得台灣彈藥表。 |
| 美式5吋／38彈藥 | 1950年代起 | 高爆／防空、照明、練習等需逐案確認 | 曾用火砲不代表取得美軍全套彈種；Mk32、Mk35等網路型號不在此列作確證。 |
| 美式5吋／54彈藥 | 1990年代起 | 高爆、防空、照明、練習等需逐案確認 | Mk42與Mk45用彈的具體組合待核。 |
| 3吋／50彈藥 | 1950年代起 | 高爆、防空／近炸與練習類待核 | 舊式3吋炮彈，不與76／62彈互列。 |
| 76／62彈藥 | 1970年代末起 | HE、近炸HE、TP／BL&P等查核類別 | 火砲系統存在確證；台灣彈體Mark／Mod與引信型號未獲直接配發證據。[U04][U04] |
| 76mm SAPOM／SAPOMER | 原廠現代產品 | 半穿甲、增程半穿甲系列 | **相容／產品參考**；原廠列SAPOMER，未確認海軍採購，不列現役彈。[U07][U07] |
| 76mm DART | 2010年代原廠產品 | 導引砲彈 | **非台灣採用證據**；需相應導引改裝，單憑裝76mm艦砲不可認定可用。[U06][U06] |
| 76mm Vulcano | 近年原廠產品 | 增程／導引產品系列 | **產品參考**；未確認台灣採用，不當海軍現役彈。[U07][U07] |
| 127mm ERGM／Vulcano等導引彈 | 國外研製與產品 | 名稱供排除誤列 | 未找到台灣海軍採用證據；不能因基隆有5吋砲就填入。 |

## 二、機砲彈藥

| 口徑／對應武器 | 具體型號／彈種 | 本次可確認到的層級 |
|---|---|---|
| 40mm L/60 | HE-T、AP-T等；台灣完整型號待核 | 彈種入口；不把L/70彈列為L/60彈。 |
| 40mm L/70 | HE、HE-T、近炸類；台灣完整型號待核 | 彈種入口；需要砲座與信管支援的證據。 |
| Bofors 40mm 3P | 3P可程式多功能彈 | 台灣海軍配發待核；不能由「L/70」自動推定取得與支援3P。 |
| 30mm Mk44相關 | HEI-T、APFSDS-T等候選彈種 | 台灣**艦用**配發待核；車用採購不等於海軍採購。 |
| 20mm Phalanx | **Mk149 APDS系列** | 原廠Mk244資料提及Mk149比較基準；台灣使用的Mod0、Mod2、Mod4等未核實，不宣稱貧鈾彈配發。[U05][U05] |
| 20mm Phalanx Block1B | **Mk244 Mod0 APDS／ELC** | 原廠產品型號確證；台灣Block1B採購確證，**兩者不構成該彈已配發的直接證據**。[U05][U05][R06][R06] |
| 20mm T75系列 | HEI、TP等；完整彈型待核 | 必須先確認機砲型及彈殼規格，再決定可否與其他20mm彈共用。 |
| 20mm Oerlikon | 專用20mm彈；HE、AP等候選 | 不因同為20mm就與方陣M61系統共用。 |
| 日製25mm | 九六式機砲用彈的候選系列 | 台灣使用批次、引信與彈型待核。 |

## 三、海軍陸戰隊火砲與迫砲彈

國軍官方文獻可找到下列**確切名稱**，但該文不是陸戰隊年度配發表。故「國軍彈型確證」與「陸戰隊實際配發」分開處理。[N38][N38]

| 武器／口徑 | 型號／名稱 | 判定 |
|---|---|---|
| 60mm迫擊砲 | **M42A1B3式60公厘高爆榴彈** | 官方文獻型號；陸戰隊使用批次待核。[N38][N38] |
| 81mm迫擊砲 | **M43A1B1式81公厘高爆榴彈** | 官方文獻型號；陸戰隊使用批次待核。[N38][N38] |
| 120mm迫擊砲 | **63A1B1式120公厘高爆榴彈** | 官方文獻型號；不可與戰車120mm砲彈混同。[N38][N38] |
| M30 4.2吋迫砲 | **M329式4.2吋高爆榴彈** | 官方文獻型號；並不因此確認陸戰隊仍使用。[N38][N38] |
| 105mm榴彈砲 | M1 HE等候選 | 精確台灣／陸戰隊配發證據待核；不要與105mm戰車砲彈混同。 |
| M109A2 155mm | M107 HE等候選 | 官方證實陸戰隊M109A2，但尚未核實其特定彈型配發；不把Excalibur等美軍新彈列入。[N25][N25] |
| 105mm戰車砲 | APDS、APFSDS、HEAT、HESH等類別 | 陸戰隊M60A3具體批次待核；M735／M774／M833等不凭口徑推定。 |
| 90mm戰車砲 | AP、HE、HEAT等類別 | 舊戰車歷史用彈；具體M型號待核。 |

## 四、機槍、步槍及榴彈

| 武器／口徑 | 彈型層級 | 判定 |
|---|---|---|
| M2 .50／12.7mm | 普通、穿甲、穿甲燃燒、曳光 | M2、M8、M20等美軍彈型與台灣國造對應待核，不視為全採用。 |
| M1／BAR／早期美式步槍機槍 | .30-06類 | 歷史武器配發與台灣具體彈型待核。 |
| M14／M60／T74等 | 7.62mm NATO類 | 國造、進口、普通、曳光與狙擊彈分開；具體型號待核。 |
| T65／T91等 | 5.56mm類 | 不能由口徑推定彈頭重量或SS109相容性；需枪型、槍管與配彈證據。 |
| 手槍與衝鋒槍 | 9mm、.45等 | 按實際配發槍型再核彈型。 |
| Mk19等自動榴彈發射器 | 40mm高速榴彈 | 不與M79／T85等低速40mm榴彈混用。 |
| M79／T85等肩射／下掛榴彈發射器 | 40mm低速榴彈 | 台灣具體高爆、兩用、煙幕、照明型號待核。 |

## 五、仍缺少的關鍵資料

目前沒有公開來源足以完成1950年至今海軍**每種砲彈的Mark、Mod、引信、裝藥與配發起迄年**。後續最有價值的資料是公開採購規格書、海軍彈藥教範、軍品展示的清楚銘牌和可辨識年份的彈體標示；應按單項補證，而不是把相容彈整批列為已用。

正式資料表宜分成「彈體型號」「引信型號」「完整定裝彈型號」三欄；同一砲彈可能配不同引信，Mark號也可能在不同口徑重複。
