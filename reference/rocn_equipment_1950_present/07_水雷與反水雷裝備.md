# 07 水雷、布雷與反水雷裝備

[回總覽](README.md)｜整理日期：2026-09-10

## 一、水雷

| 名稱／型號 | 時期 | 類型層級 | 使用與型號判定 |
|---|---|---|---|
| 早期日製遺留水雷 | 1950年代研究範圍 | 觸發／繫留型等須逐型查 | 有歷史查找線索，但本次未確定具體日本年式與台灣使用批次。 |
| 美製舊式水雷 | 冷戰時期研究範圍 | 繫留／沉底等 | 本次未取得足以列出完整Mk系列的海軍配發文件；不把美國水雷型錄全部納入。 |
| **萬象水雷系列** | 冷戰後期至近年 | 國造水雷 | 海軍實施萬象布雷演訓有直接報導；系列使用確證。[R04][R04] |
| 萬象一型／一號 | 1980年代研製資料範圍 | 文獻命名有差異 | 細型待核；研發完成年不一定等於海軍撥交年，不指定未核實的統一服役年。 |
| 萬象二型／二號 | 冷戰後期至近年 | 海軍文獻列感應繫留雷 | 型號可見官方研究；不同文獻對研製／交付年代與型式有歧異，不合併為單一確定規格。[N37][N37] |
| 萬象三型／火箭助推水雷 | 研製／試驗研究範圍 | 特殊水雷 | 未確認海軍量產接裝，不列已服役。 |
| WSM-210等公開流傳代碼 | 待核 | 與萬象及沉底雷的對應存在混用 | 未找到足夠直接來源，保留查核名稱，不直接當萬象二型的正式別名。 |
| 智慧型、遙控、自航水雷 | 新型研製／武選範圍 | 概念或不同專案 | 廠商研製能力不等於海軍採購；未確認正式型號前不列現役。 |
| Mk60 CAPTOR、Mk67 SLMM、Mk62／63／65 Quickstrike | 國外水雷系列 | 排除誤列 | 本次未確認海軍取得，不因能由美製飛機／潛艦施放就列入。 |

## 二、布雷載具

| 載具／裝備 | 用途 | 判定 |
|---|---|---|
| 快速布雷艇FMLB | 專用水雷運載與施放 | 官方海軍文獻確認使用。[N34][N34] |
| LCU通用登陸艇 | 水雷運輸及布雷支援 | 官方文獻確認參與布雷單位編組。[N34][N34] |
| LCM機械登陸艇 | 水雷運輸及布雷支援 | 官方文獻確認；艇型需另核。[N34][N34] |
| 艦上布雷軌、吊運及相關設備 | 水雷搬運與釋放 | 完整型號待核；不列實際作戰布雷區、位置與程序。 |

## 三、掃雷與獵雷

| 裝備家族 | 主要平台 | 狀態／精確型號 |
|---|---|---|
| 機械掃雷具 | 舊永字號及永陽等 | 具體掃具型號待裝備清冊，不由艦型推定全部原美式設備保留。 |
| 磁／聲感應掃雷設備 | 掃雷艦／艇 | 系列功能；型號待核。 |
| 獵雷聲納 | 永豐級、永靖級 | 官方確認艦艇獵雷用途；聲納具體型號、改良批次另核。[N17][N17][N15][N15] |
| 遙控滅雷載具／ROV | 獵雷艦 | PAP-104、AN/SLQ-48等是查核候選，尚未完成逐艦、逐批直接證據，不能共用單一型號。 |
| 潛水排爆與水下搜索裝備 | 排雷／救難部隊 | 潛水器材與爆破器具種類另查，不以救難艦存在推定具體軍品型號。 |
| 無人反水雷系統 | 新艦與技術發展案 | 計畫／測試與實際部隊接裝分開。 |

萬象系列的「號」「型」、沉底／繫留、研製／量產／交付年有來源差異，是本清單保留的考證缺口。演訓報導可證實水雷系列使用，但通常不能解析細型。
