# 06 魚雷、深水炸彈與反潛彈藥

[回總覽](README.md)｜整理日期：2026-09-10

## 一、輕型魚雷

| 型號 | 口徑 | 時期／關聯載台 | 台灣使用判定 |
|---|---|---|---|
| Mk44系列 | 約324mm | 冷戰時期艦艇及反潛航空器的查核入口 | 歷史型待補直接配發證據；官方教材中的示範信文不當成真實裝備表。 |
| Mk46系列 | 約324mm | 艦射、空投與反潛火箭酬載等不同用途 | 官方預算確認海軍延壽／維持；各載台具體Mod另核。[N33][N33] |
| **Mk46 Mod5** | 約324mm | 1990年代以後海軍輕型反潛武器 | 2017年美國紀錄直接列既有Mk46 Mod5轉換Mk54；不能由此反推所有Mk46均為Mod5。[U03][U03] |
| Mk46 Mod5 NEARTIP等細分 | 約324mm | 系列性能提升 | 待核台灣不同批次完整命名與艦射／空投設定。 |
| **Mk54 Mod0 LWT改裝案** | 約324mm | 2017年公告改裝套件 | 168套是改裝案量，不是168枚當年交付完整魚雷；本次未確認全部完成改裝或艦隊配發。[U03][U03][N29][N29] |

## 二、重型魚雷

| 型號 | 口徑 | 時期／載台 | 判定 |
|---|---|---|---|
| 早期直航魚雷（美製Mk8／Mk14／Mk15等候選） | 各型多為21吋級，須逐型核對 | 1950年代魚雷艇、驅逐艦歷史查核 | **未確證的型號入口**；原美軍艦曾有魚雷管不代表移交後仍配原魚雷。 |
| 日製九三式魚雷 | 610mm | 雪風原日軍武裝 | 不列為丹陽1950年代裝備；丹陽係解除武裝後移交。[H06][H06] |
| **SUT重型魚雷** | 533mm | 劍龍級；1980年代取得 | 海軍艦史記載1983年簽約、1984–1987年交付；實戰魚雷與操雷均有記載。[N31][N31] |
| SUT Mod0等後綴 | 533mm | 海龍、海虎 | SUT系列確證，具體Mod及延壽後命名待直接文件，不混成其他德製魚雷。[N32][N32] |
| **Mk48 Mod6 Advanced Technology（6AT）** | 533mm | 劍龍改裝／國造潛艦相關採購 | 2017年46枚、2020年18枚公告；兩案不能當全數交付證明，也不是Mk48 Mod7 CBASS。[U03][U03][U02][U02] |
| 國造重型魚雷相關研發 | 待正式公開型號 | 研發查核範圍 | 本次未確認正式型號與作戰接裝；不自行命名為已服役。 |

## 三、深水炸彈與反潛投射器

| 裝備／彈種 | 時期／用途 | 證據狀態 |
|---|---|---|
| 艦尾投放式深水炸彈 | 1950年代起舊型反潛艦 | 2025年度預算仍有深水炸彈整備；具體舊式Mk6／Mk9等台灣彈型待核。[N33][N33] |
| 舷側深水炸彈投射器／K-gun類 | 舊護航艦、巡邏艦 | 歷史配置候選；投射器Mark與深彈Mark分開。 |
| Hedgehog刺蝟彈／反潛迫砲 | 舊護航、巡邏艦等 | 歷史配置查核；Mk10／Mk11等是投射系統名稱，不能直接當炸彈型號。 |
| Mousetrap捕鼠器反潛火箭 | 小型巡邏／獵潛艇候選 | 台灣逐艦配裝及Mk20／Mk22等形式待核。 |
| RUR-5 ASROC的魚雷酬載 | 部分陽字號、濟陽、基隆 | 需查該年度火箭版本與魚雷彈頭；不是所有RUR-5都用同一魚雷。 |
| 航空深水炸彈 | S-2時期等 | 台灣具體型號待核；不要把美軍核深彈列入。 |
| 操雷／Exercise Torpedo | 訓練、回收 | SUT操雷有史料支持；不要將操雷按一枚戰雷計算。[N31][N31] |
| Mk39 EMATT等水下靶標候選 | 反潛訓練 | 待補正式採購／接裝證據；靶標不是魚雷武器。 |

## 四、適用於模組的區分

艦射、空投、火箭酬載版本可共用魚雷家族名稱，但應保留不同釋放方式；操雷不應附實戰彈頭。Mk48採購與海鯤海測分别是兩件事，不能互相證明已形成戰備能力。
