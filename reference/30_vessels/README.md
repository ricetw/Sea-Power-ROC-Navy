# 30_vessels 個別裝備索引

[軍備清單總覽](../rocn_equipment_1950_present/README.md)

共62個分類檔，已於2026-09-10逐檔增補艦名／舷號、武裝、尺寸與吃水、排水量、航速、感測器及可取得的艦歷／設施資料。**資料完整度不一，並非所有歷史艦艇或每一裝備改型都已核實。** 各檔列出直接來源及仍缺資料。

## 資料讀法

- 吃水以m表示，是水線至船底或最深附件的距離；排水量以噸表示，兩者不同。
- 標準、輕載、滿載、水面及水下排水量不可混用。美國史料未說明噸制時保留原稱tons，不默認等於公噸。
- 美國原艦／日本原型、ROC接裝、後續改裝與2026年狀態分開。艦級通用值不等於各艦驗收值。
- 發射器數量、彈庫容量與某次出航裝填量分開；未公開資料不代表沒有裝備。
- 官方刊物亦可能有誤字、舊資料或引用二手資料；本次將可辨識的衝突列在檔內。
- 本次引用來源以海軍／國防部、船廠、原廠、美國海軍艦歷與檔案為主，另用現場採訪／官兵訪談核對當年展示及艦歷。

## 重要訂正

- Tacoma分類缺乏ROC接艦證據；原來涉及太倉、太湖的線索應查Cannon型。
- 信陽DD-15有海軍艦歷及1950年代服役人員回憶，可確認戰後實際服役至1961年。
- 中正191由兩個不同美艦船體先後沿用艦名／舷號，已分檔。
- 玉山下水採總統府2021年4月13日當日紀錄，不採艦型頁的2022年誤植。
- 丹江627已於2026年7月24日成軍；全系列年底交艦仍屬當時規劃，沒有提前寫成全部完成。
