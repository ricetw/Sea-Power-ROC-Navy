# 磐石油彈補給艦

[分類索引](README.md)｜[原始清單](../rocn_equipment_1950_present/01_艦艇.md)

- 本次增補整理日：2026-09-10
- 範圍：1950年代以來公開艦歷與裝備資料；年份未註明者不代表2026年即時配置。
- 讀法：吃水是水下船體深度；排水量是重量。未核實不等於沒有裝備。美艦原型值另標，不與ROC後期實裝混用。

## 艦名、舷號與沿革

磐石 AOE-532，台船建造油彈補給艦。2013年11月5日下水，2015年1月23日交艦、同年服役。

## 尺寸、吃水、排水量與航行性能

| 項目 | 公開資料 |
|---|---|
| 長／寬／吃水 | 196m／25.5m／8.6m |
| 滿載排水量 | 20,859噸 |
| 航速 | 海軍介紹22節；台船交艦報告稱滿載試航超過合約22.5節，兩者條件不同 |
| 補給設施 | 可同時對兩艦補給；4座起重機、舷側車輛門 |
| 航空／醫療 | 直升機甲板與機庫、醫療及負壓隔離設施 |

## 武裝與彈藥

國防部2015年1月25日交艦介紹明列：2門40mm快砲、2座20mm方陣近迫武器、1座四聯裝海欉樹飛彈發射器。這是交艦時配置；砲型Mod、後續換裝與實際彈量仍須分年核實。[國防部原始登艦介紹](https://www.mnd.gov.tw/en/informationservices/publication/64030)

## 感測器與作戰系統

海軍官校研究提及協聚電整合式輪機控制系統；這是機械監控，不是對敵搜索感測器。導航雷達、電戰及射控型號未在所用海軍艦型頁完整公布。

## 其他設施、版本差異與考證

台船獎項介紹確認醫療、直升機機庫、起重機和車輛装卸設施。航速官方概略值與合約驗收值不應強行擇一抹除。
