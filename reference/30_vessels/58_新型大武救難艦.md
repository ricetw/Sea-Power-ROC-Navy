# 新型大武救難艦

[分類索引](README.md)｜[原始清單](../rocn_equipment_1950_present/01_艦艇.md)

- 本次增補整理日：2026-09-10
- 範圍：1950年代以來公開艦歷與裝備資料；年份未註明者不代表2026年即時配置。
- 讀法：吃水是水下船體深度；排水量是重量。未核實不等於沒有裝備。美艦原型值另標，不與ROC後期實裝混用。

## 艦名、舷號與沿革

新型大武救難艦，舷號511，台船國造；與歷史同名船體分開。船廠交艦資料直接記錄其救難與推進設計。

## 尺寸、吃水、排水量與航行性能

| 項目 | 公開資料 |
|---|---|
| 全長／全寬 | 87m／15.5m |
| 滿載排水量 | 3,250噸 |
| 吃水 | 所用船廠交艦資料未列 |
| 最高航速 | 18節 |
| 推進 | 全電力推進、可變螺距螺槳及齒輪箱 |
| 操控 | 艏艉輔助推進與可伸縮全向推進器、動態定位 |

## 武裝與彈藥

主要為救難支援，完整自衛砲座型號與數量未在所用交艦資料列明。

## 感測器與作戰系統

動態定位系統、潛水支援系統及遙控水下載具ROV；導航雷達與ROV精確型號未公開於該文。

## 其他設施、版本差異與考證

具ROV收放、潛水與拖帶設施。船廠所述可拖帶萬噸以上、最大十萬噸級船舶，是被拖船噸位，不是本艦排水量或繫柱拉力；不可混淆。
