# 03 飛彈清單

[回總覽](README.md)｜整理日期：2026-09-10

「年代」是台灣使用或公開計畫時期。對軍售案只記錄核准／提出採購，不把核准數量填成庫存。以下精確後綴有證據缺口者明示「待核」。

## 一、反艦飛彈

| 系列／型號 | 形式 | 時期／主要載台 | 台灣使用與型號判定 |
|---|---|---|---|
| Gabriel／天使飛彈 | 艦射 | 1970年代；早期飛彈化陽字號研究入口 | 歷史待核；Mk I／Mk II與雄一的來源關係，須補直接採購與改裝文件，不能全部當雄一。 |
| 雄風一型 HF-1／HF-I | 艦射、岸置歷史型 | 1970年代末至2010年代初；海鷗、龍江等 | 官媒直接確認海鷗搭載雄一；末期載台官方確認已汰除，飛彈精確除役日另核。[N42][N42][R09][R09] |
| 雄風二型 HF-2／HF-II | 艦射 | 1990年代起；康定、光六及其他改裝艦 | 確證國造反艦飛彈；康定官方直接載明雄二。不同艦級的配載量另核。[C01][C01][N04][N04][N10][N10] |
| 雄風二型岸置型 | 固定／機動岸置 | 1990年代起；海軍岸置制海單位 | 與艦射分開建檔；裝彈數、車型及後續批次待核。 |
| 雄風三型 HF-3／HF-III | 艦射 | 2000年代後期起；成功、錦江、沱江系列 | 原廠確認超音速反艦產品；每艦開始搭載年份與雄二混載比例另核。[C02][C02] |
| 雄風三型岸置型 | 機動岸置 | 2010年代起 | 與艦射共屬雄三系列，但發射車／箱及批次另記；不自行指定未公開彈型代碼。[C02][C02] |
| 雄二／雄三增程或改良批次 | 艦射／岸置依案 | 2020年代相關案 | 待核；「雄二增程」「雄三增程」先保留描述名稱，沒有直接文件不創造正式後綴。 |
| Harpoon 魚叉／魚鏢 RGM-84系列 | 水面艦射 | 1990年代起；濟陽、基隆等 | 2002年Kidd軍售直接列**RGM-84L Block II**，精確型號有一手證據；濟陽較早期RGM-84D等批次仍待核，不能全部標Block II。[U08][U08][N05][N05] |
| Harpoon UGM-84系列／Block II | 潛射 | 2010年代起的劍龍改裝時期 | 潛射魚叉有海軍文獻；UGM-84L完整後綴、作戰彈與操演彈需採購案補證。[N32][N32] |
| Harpoon RGM-84L-4 Block II／HCDS案 | 岸置 | 2020年核准，後續交付另核 | 海軍岸置魚叉採購案；官方說明100套、400枚是案量，不代表已全部形成戰力。[R05][R05] |
| Harpoon RTM-84系列 | 訓練／測試 | 隨魚叉採購案 | 待核具體RTM-84L-4等數量；不能當成作戰反艦彈。 |
| Harpoon AGM-84系列 | 空射 | 空軍P-3C／戰機相關 | 不計海軍艦射彈庫存；軍種與載台見02表。[N35][N35] |

## 二、防空飛彈

| 系列／型號 | 類型 | 時期／載台 | 判定 |
|---|---|---|---|
| Sea Chaparral 海欉樹／RIM-72系列 | 艦載短程防空 | 武進一型時期、康定原始防空配置 | 系列歷史使用；RIM-72C等具體後綴待採購文件核實。不要與陸上MIM-72或RIM-7海麻雀混淆。[N30][N30] |
| Standard Missile 1 MR／SM-1MR／RIM-66系列 | 中程艦對空 | 武進三型、成功、部分濟陽改裝 | 確證標一使用與維持；RIM-66B／E等批次不能僅按國外同型艦反推。[N30][N30][N33][N33] |
| Standard Missile 2 MR Block IIIA／SM-2MR | 中程艦對空 | 基隆級2000年代起 | DSCA直接確認既有Block IIIA庫存與2017年補充採購；RIM-66K-2為需另補精確代碼證據的欄位，不由模組現有命名自證。[U01][U01] |
| 海劍二 TC-2N／海射型劍二 | 艦對空 | 2020年代；量產沱江、玉山及後續改裝案 | 原廠產品確證；傾斜箱射與垂直發射系統分開，不假定同一套發射器／彈箱。[C03][C03] |
| 海劍羚 Sea Oryx | 近程防空研製案 | 2010年代後期起的研發、試裝 | 計畫／測試，尚未以本次來源證實全艦隊接裝；不能以展覽模型認定服役。 |
| MIM-72 Chaparral | 陸戰隊地面防空 | 冷戰後期起 | 海軍官網列檞樹飛彈車；具體彈型／退役進度另核。[N28][N28] |
| FIM-92 Stinger 刺針 | 陸戰隊肩射／雙聯裝等 | 冷戰後期至今的查核範圍 | 待核海軍配發批次與後綴；不能把全國採購總數算給陸戰隊。 |

## 三、反潛飛彈

| 型號 | 載台 | 年代 | 判定 |
|---|---|---|---|
| RUR-5 ASROC／阿斯洛克 | 部分陽字號、濟陽、基隆的傳統發射系統 | 冷戰後期至近年 | 系列與載台需逐型裝備表核對；魚雷酬載型與核深彈型完全不同，不把美國核型列入台灣裝備。 |
| RUM-139 VL-ASROC | 垂直發射反潛火箭 | 新艦武選研究入口 | 本次未確認海軍取得／服役；Mk41採購本身不構成RUM-139採用證據。[N29][N29] |

## 四、反裝甲飛彈

BGM-71 TOW／拖式、FGM-148 Javelin／標槍列入[海軍陸戰隊清單](09_海軍陸戰隊.md)。2016年陸戰66旅聯勇演訓報導可確認使用兩系列；具體彈型後綴仍待核。[N40][N40]紅隼、M72及國造66火箭沒有導引，不歸入飛彈。

## 五、不列為海軍已服役的相似或建議裝備

| 型號 | 排除原因 |
|---|---|
| RIM-7 Sea Sparrow／RIM-162 ESSM | 官方研究文章談到不代表已購；需獨立採購、接裝證據。[N30][N30] |
| RIM-116 RAM／SeaRAM | 曾在提升研究中討論；不是海劍羚的美製型號。[N30][N30] |
| SM-2 Block IIIB、SM-3、SM-6 | 不因台灣使用SM-2 Block IIIA就推定取得其他型。 |
| 雄風二E HF-2E | 與雄二反艦彈為不同任務系統；不自動列海軍艦載反艦武器。 |
| 雲峰、萬劍、SLAM-ER、AGM-88 | 國軍其他單位或航空武器範圍；沒有海軍採用證據就不併表。 |
| Exocet飛魚 | 康定源自法國艦型，不代表沿用法國反艦彈；官方明列雄二。[N04][N04] |
