# 中華民國海軍軍備分類參考：1950年代至今

整理日期：2026-09-10。涵蓋1950年以後曾由中華民國海軍使用的主要艦級、航空器與武器系列，另收海軍陸戰隊、岸置制海裝備，以及尚未確認接裝的新裝備。

這是**公開來源的分類研究清單**，不是官方完整財產帳或即時戰備表。早期小艇、輔助船、個艦改裝、彈藥批號與精確退役日期仍有缺口；已知缺口明列於各表，不以外國同型裝備的規格補作台灣事實。目標是讓後續查資料、建立Sea Power年代變體時有可追溯的起點。

## 如何讀表

- **確證**：來源直接支持該項「存在／使用／採購事件」。不表示同列所有型號後綴、日期和數量均已確認；有疑問的欄位另註。
- **歷史索引**：已找到歷史編目，可供逐艦深入查找；未完成全部艦歷與改裝核驗。
- **待核**：型號後綴、台灣採用證據、配發軍種或接裝狀態不足，不能當成已服役清單使用。
- **相容參考**：原廠確認的彈種或系統能力，**沒有因此確認台灣購買或配發**。
- **計畫／測試**：已公開的研製、軍售或建造案；不等同成軍。
- 年代指台灣使用的約略時期；「1950年代已有」也包含1949年以前取得、1950年仍在用的裝備。
- 「近年使用」表示有近年資料；不保證截至整理日每艘仍在役，也不提供即時妥善率或部署。
- 同一裝備跨表出現是為了交叉查找，不能把各表列數相加當庫存量。

## 收錄邊界

主表以海軍裝備為核心；海軍陸戰隊另列。P-3C等空軍海上任務裝備放在航空表的「協同／軍種邊界」區。海巡艦艇不併入海軍艦艇數。未服役的飛彈與原廠相容彈藥均另區標示。

本次查核的時間上限是2026-09-10，但各項「最近可證實事件」可能較早。尤其海鯤、輕型巡防艦、Mk48與Mk54、康定升級，沒有找到足以確認完成的交付／成軍記錄時，均保留未確認狀態。

來源以海軍、國防部、原廠、美國軍售及艦史為主；官方學術刊物的外國武器介紹或改裝建議，不當成海軍採用證據。[N01][N01][N29][N29][N30][N30]
