# 10 年代索引、已知缺口與考證規則

[回總覽](README.md)｜整理日期：2026-09-10

## 一、年代索引

以下為本組清單的導覽摘要，不代表每年所有裝備同時存在；來源及精確狀態回到各分類表。

| 年代 | 主要平台方向 | 武器與資料辨識重點 |
|---|---|---|
| 1950年代 | 丹陽、早期美援陽字號、太字號、江字號、各式登陸艦 | 日製再武裝與美式換裝分开；3吋／50、5吋／25、5吋／38及各式40／20mm不能混同。 |
| 1960年代 | 美援驅逐艦與山字號、各式小艦及早期潛艇 | 原美軍武裝不一定全部移交；登陸運輸改作巡防要以台灣年表為準。 |
| 1970年代 | 後期陽字號、茄比、龍江與海鷗發展 | 飛彈化改裝開始，76mm與舊5吋砲並存；海軍航空直升機發展。 |
| 1980年代 | 武進改裝、劍龍潛艦、岸置制海及水雷發展 | 武進一、二、三型須分艦；SUT與Mk46等水下武器家族分开。 |
| 1990年代 | 成功、康定、濟陽、錦江及新獵雷艦；S-70 | SM-1、雄二、魚叉等整合各有年代；S-2T在1999年移編海軍。 |
| 2000年代 | 基隆、田單、旭海、光六；S-70後續批 | SM-2 Block IIIA與標一不同；雄三艦裝按個艦時間。 |
| 2010年代 | 磐石、沱江原型、美移交Perry、永靖 | 海鷗等退役；定翼反潛機2013年移回空軍；魚雷新採購不等於交貨。 |
| 2020年代至2026-09-10 | 量產沱江、玉山、快速布雷艇、大武；海鯤與新艦計畫 | 海劍二、岸置魚叉、Mk48／Mk54及康定升級按事件分列，保留最新完成狀態未確認項。 |

## 二、常見誤植

| 容易寫錯的項目 | 正確處理 |
|---|---|
| 所有陽字號用同一武進三型配置 | 原型、FRAM、武進改裝與後續移裝要逐艦、逐年。 |
| 銘傳級等於國造成功級 | 船體同源但建造、移交、戰系及武器改裝不同。 |
| 原型沱江等於量產塔江配置 | 分成原型及量產批次；海劍二、反艦彈與上層結構另核。 |
| 丹陽就是二戰雪風完整武裝 | 丹陽解除武裝移交，後來重裝日製與美製砲，不能保留九三式魚雷設定。[H06][H06] |
| 同名艦等於同船 | 咸陽、中正、太湖、海龍、沱江等有同名或不同代情形，必須記前身與年份。[H01][H01][H03][H03][H04][H04] |
| 76mm Mk75就是任何76mm砲 | 3吋／50與76／62不同；Compact、SR、Strales也不同。[U04][U04][U06][U06] |
| 裝Block1B方陣即已配Mk244 | 火砲採購與彈藥配發是兩項證據。[R06][R06][U05][U05] |
| RGM、UGM、AGM-84任意互換 | 分別為水面、潛射與空射家族；細後綴另核。 |
| 雄二等於雄二E | 任務與系統不同，不以名稱相似合併。 |
| 已購Mk41便已裝ESSM或VL-ASROC | 發射器採購不證實飛彈採購或個艦整合。[N29][N29][N30][N30] |
| 2017年168套Mk54等於168枚交貨 | 原文為改裝套件；要另找完成改裝與驗收資料。[U03][U03] |
| 台灣Mk48就是Mod7 CBASS | 公開軍售列Mod6 AT。[U02][U02][U03][U03] |
| P-3C是現役海軍反潛機 | 接裝計畫沿革與實際軍種分开；2013年移編空軍。[N35][N35] |
| 官方文章談某武器即本軍有裝 | 作戰研究常討論外國裝備和未來建議，需另外核證。 |

## 三、本次查核尚未填平的缺口

| 缺口 | 對使用的影響 | 後續需要的來源 |
|---|---|---|
| 1950–1970年代小艇、巡邏與港勤完整名冊 | 不能宣稱已囊括每一艘、每一型 | 公開海軍艦籍、年度名冊、移交清單。 |
| 太／山／江字號原始艦型與艦名複用 | 可能混成同一船體 | 前身艦名、原舷號與台灣艦歷雙向對照。 |
| 陽字號每艦各期武裝 | 無法直接做準確年度武器載量 | 改裝完工表、同年清楚照片、艦史。 |
| 砲彈Mark／Mod、引信及裝藥 | 多數只能到口徑／彈種層級 | 採購規格、軍品銘牌及可公開彈藥教範。 |
| Mk44等老魚雷具體批次 | 不能確認所有候選載台 | 航空／艦艇武器手冊、歷史配發文件。 |
| 水雷「萬象一／二／三」及WSM代碼對應 | 不確定不同來源是否描述同一型 | 原廠正式品項表、驗收資料、展示銘牌。 |
| Mk54改裝完成、Mk48交付和配發 | 不能把軍售案量列戰備庫存 | 最新審計、國防部答詢與正式接裝說明。 |
| 海鯤最終交付／成軍 | 本次僅能證實海測及交付展望 | 正式交艦、成軍公告。[R01][R01][R02][R02] |
| 康定升級與新輕型巡防艦 | 不能假定全級完成同一裝備 | 每艦測試、驗收、成軍公告。 |
| 陸戰隊歷年步兵與車輛細型 | 部分目前僅列查核入口 | 部隊軍史、編裝與公開採購。 |
| 電子裝備精確後綴及換裝 | 不能用同源美法艦規格代替 | 台灣逐艦裝備介紹、型號銘牌。 |

## 四、建議的單項資料格式

每筆裝備保留以下欄位：

- 中文名稱、原文名稱、正式型號、常見別名。
- 類別、使用軍種、載台及改裝分支。
- 首次取得、首次成軍、改裝完成、退役：分開記日期。
- 來源直接支持的事實、推定部分、未確認部分。
- 最後查核日與來源事件日。
- 若為彈藥：彈體、完整彈、信管與操演／戰鬥版本分开。
- 若用於遊戲近似：近似設定與史實欄位分开，不以遊戲INI作為軍備證據。

## 五、資料日期與語言

民國年換算西元為加1911；但網站「更新日期」不是軍備服役日期。頁尾全站更新日期、搜尋引擎抓取日期與文章原始日期也各不相同。美國軍售PDF搬站時間可能顯示較新，應讀內文公告日。舊式Wade–Giles艦名拼法與現代拼音不同，中文艦名、原艦名和舷號一起比對最可靠。
