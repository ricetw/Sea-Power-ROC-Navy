# 09 海軍陸戰隊裝備

[回總覽](README.md)｜整理日期：2026-09-10

陸戰隊屬海軍，故獨立收錄。此表是主要裝備型號與歷史查核入口；官方直接確認項目與尚需補證的歷史／細型分開，**不把陸軍同型裝備或全國採購數直接算給陸戰隊**。

## 一、有海軍官方介紹的裝備

| 裝備 | 大致使用時期 | 型號／武器 | 判定 |
|---|---|---|---|
| AAV7兩棲突擊車 | 2000年代起 | AAV7系列；人員輸送、指揮、救濟分支需分列 | 海軍官方確認系列；AAVP7A1／AAVC7A1／AAVR7A1與RAM/RS批次的逐型數量另核。[N26][N26] |
| M109A2自走榴彈砲 | 1980年代以後 | 155mm | 官方確認陸戰隊使用；文中M109全國總數不是陸戰隊總數。[N25][N25] |
| M88裝甲救濟車 | 冷戰後期至近年 | M88系列；精確A1／A2等另核 | 海軍陸戰隊官方裝備索引列出；不自行升級成M88A2。 |
| Chaparral檞樹飛彈車 | 冷戰後期至近年 | MIM-72系統 | 官方確認；車型及彈型細分、退役進度另核。[N28][N28] |
| 紅隼反裝甲火箭 | 2010年代起 | Kestrel一次性反裝甲火箭 | 官方裝備介紹確認；不是導引飛彈。[N27][N27] |

M88所在官方索引：[海軍陸戰隊裝備](https://navy.mnd.gov.tw/AboutUs/Other_List.aspx?ID=2)。

另有官方軍史記載2009年以M60A3編成陸戰隊戰車營，2016年陸戰66旅聯勇報導則確認標槍與拖式使用；這些系列已有海軍／陸戰隊使用證據，但細型和年度數量仍要分開查。[N41][N41][N40][N40]

## 二、1950年代以後裝甲與兩棲載具查核項

下列名稱供補查歷史照片、軍史與編裝表；本次尚未將每一型及其起迄年全部證實，不應整區當成「確證裝備」。

| 型號／家族 | 年代研究範圍 | 分類與待核內容 |
|---|---|---|
| LVT-4及LVT系列 | 1950年代起 | 1958年運補史證實LVT使用；確切亞型與是否陸戰隊編制逐車核對。[N39][N39] |
| LVT(A)-4／LVT(A)-5 | 冷戰前中期 | 兩棲火力支援車；與運輸型LVT分開，台灣細型與改裝待核。 |
| LVTP-5 | 冷戰中後期至AAV7換裝前後 | 大型兩棲運兵車；使用起迄年待核。 |
| LVTH-6 | 冷戰中後期 | 105mm兩棲火力支援車；不算LVTP-5運兵車同武器變體。 |
| M24 Chaffee | 1950年代起的查核範圍 | 輕戰車；陸戰隊配發與批次待核。 |
| M41 Walker Bulldog／M41D | 冷戰中後期及改裝期 | 基本型與國造柴油改裝型分開；不假設兩型均在所有陸戰旅配發。 |
| M48A3 | 冷戰後期 | 舊主力戰車候選；與M48H／CM11不同。 |
| M60A3 TTS | 近年主力戰車查核 | M60A3系列使用確證：官方軍史述2009年移撥編成；TTS細分與之後存量另核。[N41][N41] |
| M113／CM21系列 | 冷戰後期至近年 | 裝甲運兵、指揮、迫砲、反裝甲分支；完整台灣細型待核。 |
| CM22／CM23 | 近年迫砲裝甲車查核 | 不能把載具名當迫砲彈型。 |
| CM25 | 近年拖式載具查核 | 車、發射器與TOW彈型需分開核證。 |
| HMMWV／悍馬系列 | 冷戰末期至近年 | 運輸、武器載台、指揮等；M998、M1045等細型需照片與清冊。 |
| 戰術卡車、救護車、工兵車 | 全時段 | 型號與批次尚未整理完全，不填推測數量。 |
| M1A2T、CM34等 | 其他軍種／新式裝備排除入口 | 沒有陸戰隊接裝證據，不能因國軍採購就列陸戰隊現役。 |

## 三、火砲、防空及反裝甲查核項

| 武器 | 口徑／系列 | 年代與狀態 |
|---|---|---|
| M101／M101A1牽引榴彈砲 | 105mm | 冷戰火砲查核；陸戰隊具體配發年待核。 |
| M114／M114A1牽引榴彈砲 | 155mm | 冷戰火砲查核；與M109自走砲分開。 |
| M109A1B與其他M109分型 | 155mm | 官網述國軍採購兩型，但不能據此判定陸戰隊每型皆配發。[N25][N25] |
| M20／M40無後座力砲 | 75／106mm等 | 冷戰反裝甲查核；台灣採用亞型及時間待核。 |
| 60mm迫擊砲 | 國造T75等候選 | 武器型號與彈型別混用；配發證據待核。 |
| 81mm迫擊砲 | 國造T75等候選 | 同為T75名稱須加口徑；彈型見05表。[N38][N38] |
| 120mm迫擊砲 | 國造系列 | 台灣彈藥型號有官方資料，陸戰隊編裝另核。[N38][N38] |
| M30迫砲 | 4.2吋 | 歷史使用待核；不當成120mm。 |
| BGM-71 TOW／拖式 | 反戰車飛彈 | 2016年陸戰66旅聯勇使用確證；TOW2A／2B及具體後綴、年度配發待核。[N40][N40] |
| FGM-148 Javelin／標槍 | 反戰車飛彈 | 2016年陸戰66旅聯勇使用確證；具體批次待核，不把全國軍售數量算給本軍。[N40][N40] |
| M72／國造一式66mm火箭 | 無導引反裝甲火箭 | 海軍紅隼介紹提及國造66火箭家族，具體陸戰隊時期另核。[N27][N27] |
| SMAW肩射多用途攻擊武器 | 火箭系統 | 陸戰隊歷史配發與彈種待直接資料。 |
| FIM-92刺針 | 肩射／雙聯裝等 | 後綴、發射架及配發單位待核。 |
| 40mm／20mm地面防空砲 | Bofors／國造等候選 | 系列與艦用版本分開；不直接移用艦艇數量。 |

## 四、步兵武器查核項

| 型號家族 | 類別 | 需確認事項 |
|---|---|---|
| M1 Garand、M1／M2 Carbine | 早期步槍／卡賓槍 | 1950年代配發與後續退出時間。 |
| M1918 BAR、M1919系列 | 早期支援武器 | 精確型號與陸戰隊直接使用證據。 |
| Thompson、M3／M3A1 | 衝鋒槍 | 特戰、車組及一般部隊配發區分。 |
| M14／國造57式 | 戰鬥步槍 | 國造與進口分開，不全部以M14編號代稱。 |
| T65、T65K2 | 突擊步槍 | 基本型與改良型接裝年代。 |
| T91 | 戰鬥步槍 | 各單位換裝與配件不等於同時全面換裝。 |
| T112 | 新型戰鬥步槍 | 國軍量產不代表陸戰隊已全面配發，列接裝待核。 |
| T75系列手槍／其他軍用手槍 | 手槍 | 與T75機砲、迫砲不同，不按「T75」一詞合併。 |
| FN Minimi／T75班用機槍 | 班用支援武器 | 進口、授權或國造細型與配發待核。 |
| M60／T74／FN MAG系列 | 通用機槍 | 不由7.62mm口徑推定完整型號。 |
| M2HB | 重機槍 | 艦上、車載與地面架設分开。 |
| M79、T85等 | 低速榴彈發射器 | 40mm低速彈，和Mk19高速彈分开。 |
| Mk19 | 自動榴彈發射器 | 具體Mod與陸戰隊配發待核。 |
| 狙擊槍、特戰專用步槍與潛水武器 | 各型 | 本次尚未完成可驗證名冊，不憑民間照片或全軍列表填型號。 |

本檔的確證覆蓋度低於艦艇主表；已提供主要查核型號與清楚邊界。若要建立正式陸戰隊逐年編裝，需以部隊軍史及公開採購再逐項縮小不確定性。
