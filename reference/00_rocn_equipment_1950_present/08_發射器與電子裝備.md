# 08 發射器、戰系與電子裝備查核清單

[回總覽](README.md)｜整理日期：2026-09-10

本附表供把「船—武器—感測器」關係拆開。**來源證實到哪一層即停在哪一層**；未取得逐艦原始裝備表的型號一律列查核項，不是全部已確認的海軍配裝清單。

## 一、武器發射器

| 型號／家族 | 對應武器與主要查核載台 | 狀態 |
|---|---|---|
| Mk13單臂飛彈發射系統 | 國造成功級的標一 | 官方升級研究直接提及Mk13與標準飛彈。[N30][N30] |
| Mk26雙臂發射系統 | 基隆級SM-2／ASROC | 主要查核型號；具體Mod、彈庫配置需另補直接來源。[N02][N02][U01][U01] |
| Mk112八聯裝ASROC發射器 | 濟陽、部分陽字號 | 查核型號；濟陽魚叉整合與各年度可用彈種分開。 |
| 武進三型標一箱式發射架 | 部分陽字號；後移裝濟陽 | 歷史查核項；發射架不是Mk13也不是VLS。[N30][N30][N33][N33] |
| Mk141魚叉箱式發射架 | 基隆等水面艦 | 查核型號；與ASROC發射器整合的魚叉分開。 |
| 雄一發射架 | 海鷗、龍江、陽字號歷史改裝 | 細型與聯裝數待核；不由雄二外觀反推。 |
| 雄二、雄三發射箱／架 | 國造艦及岸置系統 | 家族確證；各聯裝形式、箱長、底座按照片與批次核對。[C01][C01][C02][C02] |
| 海劍二箱式／垂直發射系統 | 量產沱江、玉山、升級艦 | 原廠飛彈產品確證；不同發射系統需獨立記錄。[C03][C03] |
| Mk41垂直發射系統 | 2017年相關採購案 | 國防部有軍售程序說明；不等於任一現役艦已裝，不據此認定ESSM或VL-ASROC已服役。[N29][N29] |
| Mk32輕型魚雷發射管 | 現代水面反潛艦 | 查核型號；三聯裝架、管身及Mod號另核。 |
| 533mm潛艦魚雷管 | 劍龍／國造潛艦 | 口徑及武器家族有文獻；國造與荷製發射系统不能視為同型。[N32][N32] |

## 二、戰鬥系統

| 系統／名稱 | 年代與載台範圍 | 判定 |
|---|---|---|
| 武進一／二／三型 | 陽字號不同改裝案 | 必須分案、分艦，不把所有陽字號標成武進三；其裝備移用與新造艦戰系分開。[N24][N24][N30][N30] |
| H-930／H-930 MCS家族 | 武進與國造巡邏艦等 | 完整Mod、軟體版及武器整合待核；相同商用名稱不代表同功能。 |
| Mk92射控系統 | 成功／Perry型相关 | 美國Mk75文件確認系统配合關係；台灣CAS／STIR與改良版本仍須逐艦證據。[U04][U04] |
| WDS Mk14 | 基隆級SM-2相關 | 海軍成功級升級研究明確指出基隆使用此系統。[N30][N30] |
| 劍龍級戰系提升 | 2020年代相關預算 | 計畫存在確證；不把預算年度當完成年度。[R06][R06] |

## 三、雷達、聲納與電子戰型號索引

下列供逐項比對照片、艦史及接裝資料，**精確配裝尚未在本次查核中完全證實**。

| 家族／候選型號 | 對應查核方向 | 必須補證的內容 |
|---|---|---|
| AN/SPS-6、SPS-10、SPS-12等 | 早期美製艦搜索雷達 | 移交／改裝年代、天線形狀與具體後綴。 |
| AN/SPS-40、SPS-49 | 冷戰後期與二代艦對空搜索 | 各艦配置、版本與替換事件。 |
| AN/SPS-48 | 基隆級三維對空搜索 | 具體字母型及後續提升狀態。 |
| AN/SPS-55 | 美製艦平面搜索 | 系統與台灣逐艦保留狀態。 |
| Sea Tiger／Triton系列 | 康定級搜索雷達查核 | 原法文型號、中文別名、改裝前後。 |
| CS/SPS-2B、CS/SPG-6N等 | 國造搜索／射控雷達 | 精確型號與首裝年份。 |
| STIR／SPG-60等照明與射控 | 標一／艦砲相關 | 同一雷達與不同戰系的整合不能推定。 |
| AN/SQS-23、SQS-26、SQS-53等 | 陽字號、濟陽、基隆艦艏聲納 | 不同艦型對應的細型與改良狀態。 |
| AN/SQS-56、SQR-19等 | 成功／Perry相關 | 原美軍配備與台灣實裝須分開。 |
| 法製艦艏／拖曳聲納 | 康定級 | 具體DUBV系列型號待核，不將原法國La Fayette缺裝狀態套來。 |
| 航空吊放聲納、聲納浮標 | S-70、500MD、S-2時期 | 機型、批次、消耗性浮標型號。 |
| **AN/SLQ-32(V)系統性能提升** | 基隆等艦相關2017軍售 | 國防部證實計畫；(V)3等具體配置與交付日期另核。[N29][N29] |
| Mk36 SRBOC、CR-201、國造誘餌系統 | 不同艦反飛彈誘餌 | 發射架、干擾彈型號、箔條／紅外線效果分開。 |
| 魚雷誘餌／拖曳聲學誘餌 | 水面艦、潛艦 | 不因有誘餌發射口就推定確切彈型或效能。 |

本附表不列雷達工作參數、實際部署、盲區與戰術使用方法；重點是資料命名和年代辨識。
