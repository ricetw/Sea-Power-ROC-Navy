# 04 艦砲、機砲與艦用機槍

[回總覽](README.md)｜整理日期：2026-09-10

本表把火砲本體和砲彈分開。早期砲管Mark、砲座Mark與後來改裝沒有全部取得直接裝備表，所列精確名稱有「待核」標記者只能當查核入口，不能作確證的台灣規格。

## 一、艦砲

| 火砲／型式 | 口徑與倍徑 | 台灣時期／主要候選載台 | 證據與差異 |
|---|---|---|---|
| 日製艦砲／高角砲 | 100、120、127mm等需逐艦核對 | 丹陽1952年再武裝及早期賠償艦 | 丹陽使用戰後留台日製砲確證；八九式127mm／40、九八式100mm／65等細分待原始檔案，不保留雪風原裝砲假設。[H06][H06] |
| 美式5吋／38艦砲，常見Mk12砲管 | 127mm／38 | 美製陽字號；不同單、雙聯砲座 | 歷史查核型；Mk30、Mk38等砲座號必須跟砲管分開，台灣改裝後数量逐艦核對。[H08][H08] |
| 美式5吋／25艦砲 | 127mm／25 | 丹陽美式換裝期的候選型 | 待核細型及數量；不可把5吋／25與5吋／38混成同一炮。 |
| Mk42艦砲 | 127mm／54 | 濟陽級 | 主要型號查核入口；Mod號與拆換紀錄待核。[N05][N05] |
| Mk45艦砲 | 127mm／54 | 基隆級 | 官方射擊紀錄確認5吋砲使用；Mk45細型另核，不能因美軍升級就寫成62倍徑Mod4。[N02][N02][N43][N43] |
| 美式3吋／50艦砲 | 76.2mm／50 | 太字號、山字號、江字號、登陸艦等 | 歷史查核型；Mk22等手動型與Mk33雙聯自動砲座分开，彈藥也不能與76／62共用。[H07][H07][H09][H09] |
| OTO Melara 76／62 Compact；美製Mk75 | 76.2mm／62 | 龍江、武進改裝、成功、康定、部分錦江等 | Mk75與原廠76／62關係由美海軍官方確認；各台灣艦的製造廠、Mod號另核。[U04][U04] |
| OTO 76／62 Super Rapid | 76.2mm／62 | 新艦／改裝武選查核項 | 待核台灣逐艦採用；換匿蹤砲罩不證明換成SR或具DART導引能力。[U07][U07][U06][U06] |
| 國造76mm砲／砲罩、控制系統改良 | 76.2mm級 | 近年國造艦 | 名稱與國產範圍待核；砲罩國造不等於砲管、供彈、彈藥全部國造。 |

## 二、40mm以下火砲

| 型式 | 口徑 | 大致台灣時期／用途 | 證據狀態 |
|---|---|---|---|
| Bofors 40mm L/60 | 40mm | 1950年代已有；舊驅逐、巡邏、掃雷、登陸與勤務艦 | 歷史型；單、雙、四聯砲座另核，不等同L/70。[H07][H07][H08][H08] |
| Bofors 40mm L/70 | 40mm | 武進改裝及較新艦艇的副砲 | 待核每艦砲座與控制型式；不能由「40快砲」三字確定L/70。 |
| Bofors／Breda 40mm雙聯型 | 40mm | 康定等艦的副砲查核項 | 待核具體砲座名稱、批次與射控；與成功級單裝副砲分開。 |
| 國造T92 40mm快砲 | 40mm | 陸用／艦用衍生型查核範圍 | 國造陸用砲存在不證明某艦已裝；台灣海軍配裝需獨立證據。 |
| 30mm遙控武器站／Mk44 Bushmaster II相關 | 30mm | 近年國造勤務、布雷及新造艦候選 | 待核台灣艦用武器站完整型號；國軍CM34車用Mk44不能直接当艦用採購證明。 |
| Mk15 Phalanx方陣CIWS | 20mm | 武進三型及多種現代艦 | 官方預算證實Block1B採購；Block0／1／1A／1B須逐座分開，不統一改成1B。[R06][R06] |
| T75系列20mm機砲／T75S艦用配置 | 20mm | 小艇、勤務艦等 | 官媒直接記載海鷗配T75 20mm機砲；S等後綴與其他載台仍待核，必須加口徑與用途。[N42][N42] |
| Oerlikon厄利孔20mm | 20mm | 1950年代已有；舊艦自衛 | 歷史型；彈殼規格、供彈與國造20mm型不同，不共用彈藥條目。[H07][H07] |
| 日製九六式25mm機砲 | 25mm | 早期日製裝備查核範圍 | 待核各艦實際保留／移裝，不能由日軍原始艦裝反推。 |
| Browning M2HB／.50機槍 | 12.7mm | 全時段多種艦艇自衛 | 官媒確認海鷗12.7mm機槍2挺；M2HB精確型號與其他艦艇數量仍待核。[N42][N42] |
| 7.62mm艦用機槍 | 7.62mm | 登檢、小艇與警戒 | 型號／配發待核，不能只由照片遠景確認M60、T74或MAG。 |

## 三、建檔時應拆分

1. 火砲本體：口徑、倍徑、砲管型號。
2. 砲座：單／雙聯、砲座Mark／Mod、砲罩外觀。
3. 射控：手動、遙控、雷達／光電及改裝時期。
4. 彈藥：見05表；相同口徑不代表通用。
5. 可證實年份：同一艦可能保留舊砲、改換雷達或僅換外罩；應各自記錄。

本表列出需要比對的主要型號，不將未經證實的砲座Mod號補成確定答案。
